# Data Folder

This folder is for local datasets and generated feature files.

The actual dataset folders are ignored by Git because they are large and can be downloaded or regenerated:

- `fashion_mnist/`
- `deepfashion/`
- `deepfashion2/`
- `polyvore/`
- `processed/`

The notebooks and setup scripts expect these folders when training or rebuilding features. The demo models in `../models/` are enough for the basic project walkthrough.
